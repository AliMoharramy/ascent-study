# 02 — دامنهٔ کنکور و دادههای مرجع

> منبع اصلی: cshub.ir (سامانهٔ مستقل کنکور کامپیوتر؛ مؤسس: پویا خانی، رتبهٔ ۱۰ کنکور ۱۳۹۹).
> استخراج: 22 آبان 1405. همهٔ ادعاهای آماری «ادعای منبع» است و باید با بانک کارنامه‌ها اعتبارسنجی شود.
> ⚠ cshub بانک تست و آزمون آزمایشی می‌فروشد (منفعت تجاری)؛ توصیه‌ها را به‌عنوان فرضیه بخوان.

## 1. ساختار آزمون ۱۴۰۶ (نخستین آزمون با قالب جدید)

| بخش | دروس | نکته |
|---|---|---|
| زبان انگلیسی | زبان عمومی + زبان تخصصی | ۳ مبحث: لغت، گرامر، درک مطلب تخصصی |
| ریاضیات | ریاضیات گسسته، آمار و احتمال مهندسی، **جبر خطی (جدید)** | ریاضی عمومی ۱ و ۲ حذف شد |
| دروس تخصصی (۷ درس، ضریب یکسان) | مبانی کامپیوتر و برنامه‌سازی، مدار منطقی، معماری کامپیوتر، داده‌ساختارها و الگوریتم‌ها، نظریه زبان‌ها و ماشین‌ها، سیستم‌عامل، هوش مصنوعی | یک مجموعهٔ واحد؛ «تخصصی ۱/۲/۳» حذف شد |

- **رتبهٔ واحد:** ۴ کد ضریب قبلی حذف شده؛ یک رتبه برای همهٔ گرایش‌های «مهندسی و علم کامپیوتر».
- ضرایب کد ۱۲۷۷ (T-DATA-02): **زبان ۱، ریاضیات ۲، تخصصی ۴** (سهم وزنی ۱۴.۳٪ / ۲۸.۶٪ / ۵۷.۱٪). جزئیات: `docs/research/T-DATA-02-coefficients.md`، `seed/exam-structure.yaml`.
- **تعداد سؤال هر درس و مدت آزمون ۱۴۰۶: هنوز اعلام نشده** — فرض موقت (۱۴۰۵): ۲۵+۲۰+۴×۲۰+۱۰ = ۱۱۵ سؤال، ۲۴۰ دقیقه (`assumed: true`). بازهٔ گزارش‌شدهٔ آزمون ۱۶–۱۷ اردیبهشت ۱۴۰۶ است؛ تاریخ برنامه‌ریزی و پایان کمپین طبق تصمیم کاربر **۱۶ اردیبهشت** تنظیم شده است (`docs/research/T-DATA-01-exam-date.md`).
- تصمیم کاربر: جبر خطی خوانده نمی‌شود (status: dropped در `seed/subjects.yaml`).

## 3. هدف کمّی (ادعای cshub — با ساختار قدیم)

| هدف | میانگین درصد خالص (با احتساب منفی) |
|---|---|
| رتبهٔ تک‌رقمی | ≈ ۵۰ تا ۵۵٪ |
| رتبهٔ زیر ۱۰۰ | ≈ ۳۵٪ |
| قبولی در دانشگاه‌های تهران | ≈ ۲۵ تا ۳۰٪ |

- شرکت‌کنندگان کنکور ارشد مهندسی کامپیوتر: حدود ۱۰٬۰۰۰ تا ۱۵٬۰۰۰ نفر.
- حدود ۳۰٪ ظرفیت هر دانشگاه به سهمیه‌ها (۵٪ و ۲۵٪ ایثارگران) اختصاص دارد؛ رتبهٔ آزاد قبولی باید با آن تعدیل شود.
- ~~پیشنهاد اولیه: ۳۵٪~~ ← **به‌روز (v0.2، ADR-0006): هدف عملیاتی = ۴۰٪ تراز وزنی؛ کف ۳۵٪؛ کشش ۴۵٪** بر پایهٔ ۲٬۵۱۸ کارنامه (docs/research/T-DATA-04). متن قبلی: هدف عملیاتی سیستم = **۳۵٪ خالص در آزمون‌های جامع** (با حاشیه برای عدم قطعیت ساختار جدید). این عدد در گام T-DATA-04 با فیلتر کارنامه‌های شریف/امیرکبیر/علم‌وصنعت/تهران بازبینی می‌شود.
- معنای عملی: **تسلط بر همهٔ چیز لازم نیست**؛ باید روی فصل‌های پربازده‌ی هر درس تسلط واقعی ساخت و از نزدن‌ها و غلط‌ها (نمره‌ی منفی) پرهیز کرد.

## 4. آزمون‌های آزمایشی cshub

- ۱۳ مرحله، سؤال تألیفی، کارنامهٔ روزانه، پاسخ تشریحی، گروه رفع اشکال.
- پس از تاریخ اصلی «شناور» می‌شوند. دعوت به آزمون به‌صورت دستی هر یکشنبه و چهارشنبه شب انجام می‌شود (مهم: برای شروع شناور، منتظر دعوت بمان).
- کاربر ثبت‌نام کرده است. **تصمیم:** آزمون‌ها در پایان (فاز Arena) پشت‌سرهم از اول داده می‌شوند.
- جدول کامل: `docs/seed/mock-exams.yaml`.

## 5. منابع پیشنهادی cshub (برای دروس کاربر)

| درس | منبع اصلی پیشنهادی | برای کاربر |
|---|---|---|
| هوش مصنوعی | ویدیو درس + نکته‌وتست محمد انصاری (با اختلاف زیاد بهترین) | دارد |
| داده‌ساختار/الگوریتم | انصاری یا یوسفی؛ ترکیب هم ممکن | دارد: نکته‌وتست انصاری (96 ساعت) |
| نظریه | ویدیو درسنامهٔ فردین شاپوری؛ تست از بانک cshub | دارد (پلتفرم/منبع مشخص‌نشده) |
| مدار منطقی | یوسفی یا باغستانی | دارد |
| معماری | درسنامه: باغستانی/یوسفی؛ نکته‌وتست: یوسفی | دارد |
| گسسته | یوسفی (ویدیو درس + نکته‌وتست) | دارد |
| آمار و احتمال | آقای قمی (بینش)؛ مسیر سریع: «مکتب گرام» + بانک تست | دارد |
| سیستم‌عامل | (در متن منابع ذکر نشده) — حقیقت در پرلایک | دارد: آموزشی + نکته‌وتست |
| مبانی برنامه‌سازی | منابع رایگان (گنج‌تابش، جزوه‌ها) | فقط تست |
| زبان | ۱۵۰۰–۱۶۰۰ تست در پلتفرم بانک تست cshub | ۲۰ دقیقه در روز |

توصیهٔ cshub: برای کسی که ≥ ۴/۵ ماه مانده شروع می‌کند، بانک تست برای همهٔ دروس خریده شود.
