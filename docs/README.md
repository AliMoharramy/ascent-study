## خلاصهٔ یک‌صفحه‌ای

- **۲۵ هفته** تا کنکور؛ ظرفیت واقعی ≈ ۴۲۶ ساعت برای ۸ درس اصلی؛ تقاضای کامل ≈ ۷۲۴ ساعت → **شکاف ≈ ۴۱٪** → سیستم باید خودش **انتخاب‌گر (Triage)** باشد.
- **هدف عملیاتی (v0.2):** ۴۰٪ تراز وزنی (کف ۳۵٪، کشش ۴۵٪) — از ۲٬۵۱۸ کارنامهٔ cshub (ADR-0006).
- **قلب بازی:** Core Quest روزانه با سه سطح (Seed/Standard/Stretch)، XP غیرکاهشی + Score قابل‌منفی با سقف، سپر و Comeback، Shadow Rival، باس هفتگی جمعه‌ها، نقشهٔ ۴ قلمرو/۸۲ گره.
- **قلب عادت‌ها:** Baseline Week، Habit Stacking، قانون ۲ دقیقه، Never Miss Twice، برنامهٔ خواب تدریجی (۲۰ دقیقه/هفته)، اسلات یادگیری هفتگی.
- **مهار فرار:** Idea Vault + Detour Detector + **Builder Hour** (پاداش سازندگی بعد از درس) + Build Freeze از 7 اسفند.
- **استک:** Next.js + SQLite + Tailwind در یک کانتینر؛ موتورها خالص و تست‌پذیر؛ Event Sourcing سبک.
- **ساخت:** AI، مرحله‌به‌مرحله (R0 تا R5)، هر انتشار ≤ ۱۵ دقیقه از زمان کاربر.
