# 12 — تحلیل سبک UI مرجع کاربر و جهت بصری جدید

> مرجع‌ها: دو تصویر ارسالی کاربر (متعلق به اپ‌های دیگر؛ برای رعایت حقوق صاحبانشان در مخزن عمومی گنجانده نشده‌اند):
> **مرجع ۱** — اپ یادگیری با تم تیره، بلوک‌های رنگی و شخصیت‌های برداری (برند Classo در تصویر؛ ما فقط **سبک** را الهام می‌گیریم، نه برند/تصویر).
> **مرجع ۲** — اپ کوییز با تم روشن کِرِم، شخصیت‌های سه‌بعدی نرم (زنبور، ربات)، مدال‌ها و کارت‌های سفید.
> این سند جهت بصری «Obsidian & Ember» در سند 08 را **جایگزین می‌کند** (تصمیم D24؛ سند 10).

## 1. تحلیل مرجع ۱ (تیره، بلوک‌رنگی)

### 1.1 زبان بصری
- **Color‑blocking جسورانه:** کارت‌های بزرگ تک‌رنگ اشباع (زرد گرم، فیروزه‌ای/نعنایی، مرجانی/قرمز، بنفش به‌عنوان رنگ تعامل) روی پس‌زمینهٔ تقریباً سیاه.
- **تایپوگرافی:** عنوان‌ها با فونت **فشردهٔ سنگین و حروف بزرگ** (شبیه Bebas Neue/Anton)؛ اعداد بسیار بزرگ (مثلاً «86%») به‌عنوان قهرمان صفحه؛ متن‌های ثانویه ساده و سبک.
- **شعاع بزرگ:** کارت‌ها ≈ ۲۴–۲۸px؛ Chip و دکمه گرد کامل؛ دکمهٔ اصلی «سیاه روی رنگ» با فلش در دایره.
- **تصویرسازی:** برداری تخت با **خط دور ضخیم**، شخصیت‌های انسانی متنوع، جزئیات بازیگوش (جرقه، کنفتی). هر کارت یک «صحنه» دارد.
- **ناوبری:** نوار پایین ۴ تبی؛ تب فعال = **دایرهٔ پر بنفش** با آیکن و برچسب بنفش.
- **نشانگرها:** Chip وضعیت («Due tonight» با رنگ مرجانی)، نوار پیشرفت دو‌رنگ، حلقهٔ پیشرفت (۴/۷ روز فعال)، نوارهای عملکرد چندرنگ (سبز/زرد/بنفش/قرمز) با درصد.
- **چت:** حباب کاربر (بنفش تیره با لبهٔ بنفش) و حباب AI (فیروزه‌ای)، Chipهای پیشنهاد («Quiz me»)، ورودی با دکمهٔ ارسال بنفش و میکروفون.
- **صفحهٔ نتیجه:** کارت بزرگ مرجانی + درصد عظیم + شخصیت جشن + «Section performance» + کارت توصیهٔ بعدی (فیروزه‌ای) + کارت Streak (زرد، شعله) + دکمهٔ «Review mistakes».

### 1.2 حس و مخاطب
پرانرژی، جوان، «اپ بازیگوش اما جدی»؛ سلسله‌مراتب بسیار واضح (یک کارت = یک کار).

### 1.3 پالت استخراج‌شده (تقریبی از روی تصویر)
| نقش | مقدار تقریبی |
|---|---|
| پس‌زمینه | `#0E0E10` / `#16161A` |
| کارت زرد (تمرکز امروز) | `#F2C24E` |
| کارت فیروزه‌ای/نعنایی | `#8FD9D0` |
| کارت مرجانی | `#E8553F` |
| بنفش تعامل | `#7C6CF2` |
| سبز لیمویی (نوار) | `#9BD24E` |
| متن روشن | `#F5F2EA` |
| متن ثانویه | `#9A9AA3` |
(باید پس از انتخاب نهایی کاربر با ابزار رنگ‌برداری دقیق شود.)

## 2. تحلیل مرجع ۲ (روشن، شخصیت‌محور)

- **پس‌زمینه کرم گرم** (`≈ #F6EBD5`)، **کارت‌های سفید** با گرادیان ملایم و سایهٔ نرم؛ شعاع زیاد.
- **شخصیت‌های سه‌بعدی براق** (زنبور با جام، ربات خواننده، مدال‌ها) — حس «دوست‌داشتنی» و پاداش‌گونه.
- **تایپوگرافی گرد** (شبیه Nunito/Quicksand)، عنوان‌ها ساده و خوانا؛ دکمهٔ اصلی **مشکی**، ثانویه **سفید**، تأکید **زرد**.
- **صفحه‌ها:** Quiz Results (کاشی‌های آمار: «پاسخ‌های درست/زمان»)، Lesson Overview (لیست درس‌ها با وضعیت Completed / Continue / Locked)، Achievements (مدال‌های با عنوان + شرط)، Profile (آواتار + ردیف‌های آمار + Edit/Settings).
- **مدال‌ها:** دایره‌های فلزی با روبان، آیکن داخلی (ستاره، مغز، کرنومتر) و **شرط دستاورد زیرنویس** («Finished a quiz in under 2 min»).

## 3. ترکیب و تصمیم طراحی

**پیشنهاد من: «Playful Color‑Block» به‌عنوان زبان اصلی** با دو تم:

| تم | منبع الهام | استفاده |
|---|---|---|
| **Night (پیش‌فرض)** | مرجع ۱ | دسکتاپ و موبایل؛ تمرکز و شب |
| **Cream (روشن)** | مرجع ۲ | روز؛ صفحات Profile/Achievements/Results |

- **یک سبک تصویرسازی** باید انتخاب شود تا ناهماهنگی ایجاد نشود. پیشنهاد: **برداری تخت با خط دور ضخیم** (مرجع ۱) برای صحنه‌ها و شخصیت‌ها (برای تولید با AI پایدارتر و سبک‌تر است)، و **مدال‌های براق نیمه‌سه‌بعدی** فقط برای دستاوردها (مرجع ۲). *این یک تصمیم است که کاربر باید تأیید کند (Q11).*
- **تلفیق با داستان THE ASCENT:** فضای فانتزی به **«ماجراجویی بازیگوش»** تغییر می‌کند؛ قله، مه (Fog)، قلعه‌ها همچنان هستند ولی با شخصیت‌های بامزه:
  - **Hero (Ascender):** آواتار قابل‌شخصی‌سازی.
  - **Shade (Shadow Rival):** دوقلوی سایه‌ای بنفش (شیطنت‌آمیز، نه ترسناک).
  - **Archie (Archivist):** ربات/جغد مربی، صدای دستیار AI (الهام: ربات مرجع ۲).
  - **Fog Critters:** هیولاهای کوچک مه برای باس‌ها (قابل‌مغلوب‌شدن، خنده‌دار).
- **اصل ضد‌کودکانه:** لحن و کپی بالغ و کوتاه؛ تصویر بازیگوش، محتوا جدی (سند 08 §8).

## 4. Design Tokens (نسخهٔ 0.2 — جایگزین سند 08 §2.1)

### 4.1 Night
```css
:root[data-theme="night"] {
  --bg:#0E0E10; --surface-1:#16161A; --surface-2:#1E1E24; --border:#2A2A32;
  --text:#F5F2EA; --text-muted:#9A9AA3;
  --c-yellow:#F2C24E;  /* Core Quest / XP / CTA کارت */
  --c-mint:#8FD9D0;    /* درس/فصل بعدی، توصیه */
  --c-coral:#E8553F;   /* نتیجه، هشدار، Fog */
  --c-purple:#7C6CF2;  /* تعامل، ناوبری فعال، Shadow */
  --c-lime:#9BD24E;    /* موفقیت، نوار */
  --on-color:#111114;  /* متن روی کارت رنگی */
  --radius-card:26px; --radius-btn:999px; --radius-chip:999px;
}
```
### 4.2 Cream
```css
:root[data-theme="cream"] {
  --bg:#F6EBD5; --surface-1:#FFFDF8; --surface-2:#FFF7E6; --border:#EADFC8;
  --text:#1B1A17; --text-muted:#6F6A5C;
  --c-yellow:#F5B83D; --c-mint:#8FD9D0; --c-coral:#E8553F; --c-purple:#7C6CF2; --c-lime:#9BD24E;
  --btn-primary:#111114; --btn-primary-text:#FFFFFF;
  --shadow-card:0 10px 30px rgba(120,90,30,.12);
}
```
### 4.3 تایپوگرافی
| نقش | لاتین | فارسی | یادداشت |
|---|---|---|---|
| Display (عنوان‌ها و اعداد بزرگ) | Bebas Neue یا Anton | Lalezar یا Vazirmatn 900 | حروف بزرگ لاتین؛ فارسی بدون Uppercase |
| Body | Nunito (گرد) | Vazirmatn | `tabular-nums` برای اعداد |
| Mono (کد/ثبت) | JetBrains Mono | — | فقط ابزارها |
- همهٔ فونت‌ها **self‑host**؛ زیرمجموعه‌سازی (subset) برای حجم کم.
- RTL: کارت‌های رنگی **آینه** می‌شوند (تصویر شخصیت در سمت مقابل)؛ فلش‌ها آینه.

### 4.4 مقیاس
`display: 72/56/40` · `title: 28/20` · `body: 16/14` · `caption: 12`. ارتفاع خط ۱.۲ برای Display، ۱.۵ برای Body.

## 7. چیدمان دسکتاپ (Bento Grid)

مرجع‌ها موبایل‌اند؛ دسکتاپ همان زبان را به **شبکهٔ Bento** تبدیل می‌کند:

```

│ ┌──────────── TODAY'S FOCUS (yellow, 2×2) ──────┐ ┌─ MINT: NEXT CHAPTER ─┐ ┌ CORAL ┐ │
│ │  TODAY'S CORE QUEST   [illustration]          │ │ DSA · Ch.4 Trees     │ │ BOSS  │ │
│ │  هوش مصنوعی · فصل ۳                            │ │ Due tonight · 24 min │ │ Fri   │ │
│ │  ▓▓▓▓▓░░ 68%   [ Continue → ]                 │ └──────────────────────┘ │ 3d 4h │ │
│ └───────────────────────────────────────────────┘ ┌─ WEEK GLANCE ─────────┐ └───────┘ │
│ ┌─ DAILY ────┐ ┌─ PILLARS ──┐ ┌─ SHADE GAP ─┐    │ 6 lessons · ◔ 4/7 days │ ┌ STREAK ┐ │
│ │ ☐ Fundament│ │ ☐ Run ☐ Bed│ │ −28 ▓▓▓░    │    └────────────────────────┘ │ 🔥 12   │ │
```

- ستون ۱۲، فاصله ۲۰px، کارت‌ها با `span` متفاوت؛ در ۱۰۲۴ پایین‌تر به ۸ ستون.
- نوار ناوبری موبایل ↔ Rail عمودی دسکتاپ (دایرهٔ بنفش فعال).

## 8. تصویرسازی (به‌روزرسانی سند 08 §11)

### 8.1 سبک ثابت (Style Block)
```
STYLE: flat vector illustration with thick dark outlines, bold simple shapes, playful friendly characters,
limited vivid palette (warm yellow, mint, coral red, violet, lime), tiny sparkles and confetti accents,
clean background in a single solid color, no text, no watermark, centered, safe margins
```
برای مدال‌ها (فقط): `glossy semi-3D rounded badge medal with ribbon, soft studio lighting, simple icon, cream background`.

### 8.3 قواعد حقوقی
- فقط **سبک** از مرجع‌ها الهام گرفته شود؛ تصویر/شخصیت/نام برند مرجع (Classo، زنبور، ربات) **کپی نشود**.
- تصاویر AI باید اصل باشند و در مخزن به‌عنوان «original assets» ثبت شوند.

## 9. حرکت و حس
- فنری (spring) و جهنده برای کارت‌ها؛ **کنفتی** و **جهش شخصیت** در لحظه‌های پاداش.
- `prefers-reduced-motion`: جایگزین با محو ساده.
- صدا: «پاپ» کوتاه برای XP، «چایم» برای Level، «درام» برای باس (پیش‌فرض خاموش).

## 10. دسترس‌پذیری (مهم برای رنگ‌های روشن)
- متن مشکی روی زرد/فیروزه‌ای (AA)؛ متن سفید روی بنفش/مرجانی فقط با وزن ≥ ۶۰۰ و اندازه ≥ ۱۶.
- هیچ وضعیتی فقط با رنگ بیان نشود (آیکن + برچسب).
