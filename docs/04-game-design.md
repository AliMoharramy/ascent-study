# 04 — طراحی بازی: THE ASCENT

> نسخه 0.1 — همهٔ اعداد در `config` قرار می‌گیرند و **قابل تنظیم توسط کاربر** هستند (اصل مالکیت). مقادیر این سند «پیش‌فرض اولیه» هستند و پس از هفتهٔ پایه کالیبره می‌شوند.
> تم داستانی: **پیش‌فرض موقت = فانتزی حماسی با رگه‌های فناوری باستانی (arcane‑tech)**. کاربر هنوز ترجیح نهایی (فانتزی/علمی‌تخیلی/ترکیب) را اعلام نکرده و مرجع‌های ظاهری را بعداً می‌فرستد. همهٔ نام‌ها از طریق لایهٔ Theme قابل تعویض باشند.

## 1. داستان (Story Bible)

### 1.1 ایدهٔ اصلی
تو **«صعودکننده» (The Ascender)** هستی. در دنیایی که دانش در **چهار قلمرو** پراکنده است، قله‌ای وجود دارد که فقط کسانی به آن می‌رسند که از **آزمون بزرگ** عبور کنند. قله نمادِ دانشگاه‌های برتر است. اما قله «جایزه» است، نه «هدف روزانه»: هر روز فقط **یک ماموریت و نزدیک‌ترین باس** جلوی چشم است.

داستان فقط ظاهر نیست: **هر رویداد بازی از داده‌ی واقعی می‌آید** (عقب‌افتادن = «مه» روی نقشه؛ فصل Cleared = «برج روشن»؛ باخت به Rival = «سایه جلو می‌افتد»).

### 1.4 نمونهٔ متن روایت (قالب برای تولید توسط AI)
- **شروع Ch.1:** «مه غلیظ است. از آنجا که ایستاده‌ای، قله دیده نمی‌شود. فقط یک مسیر هست — و امروز فقط یک گام.»

### قوانین اقتصاد
- **قانون سهم مطالعه:** XP غیردرسی (ستون‌ها) حداکثر **۳۰٪** از کل XP هفته به Level کمک می‌کند؛ مازاد تبدیل به Gold می‌شود. (درس همیشه اول و آخر.)
- **تحلیل غلط‌ها ارزشمندتر از تست‌زدن است** (۱.۰ در برابر ۰.۶/۰.۱) چون یادگیری واقعی آنجاست.
- **نمرهٔ منفیِ آزمون در Score اثر دارد:** در Boss/Arena، SS مبتنی بر «درصد خالص» (درست − غلط/۳ در حالت چهارگزینه‌ای) است.
- ورود دستی (بعد از ۲۴ ساعت) نصف XP می‌گیرد و علامت `manual` می‌خورد.

### منحنی سطح
```
xp_to_next(n) = 120 + 12·n          # n = سطح فعلی
مجموع تا سطح L = 120·L + 6·L·(L+1)  # L=35 → 11,760 ؛ L=40 → 14,640
```
هدف: میانگین ≈ ۸۰ XP/روز ← سطح ≈ ۳۹–۴۰ در هفتهٔ آخر. سطح‌های اول سریع (≈ هر ۱.۷ روز) و بعد کندتر (هر ≈ ۷ روز در سطح ۴۰) برای حفظ حس پیشرفت و کاهش اثر تازگی.

## 5. مأموریت‌ها (Quests)

### 5.1 انواع
| نوع | تعریف | مثال |
|---|---|---|
| **Core Quest** | مأموریت اصلی روز؛ از Planner می‌آید | «امروز: هوش، فصل ۳ — ویدیو جلسه ۷–۸ + ۱۵ تست» |
| **Daily Fixed** | مأموریت‌های ثابت | ۱۰ تست مبانی، ۲۰ دقیقه زبان |
| **Pillar Quest** | ستون‌ها: Rest/Body/Read/Bonds | بیداری ≤ ۶:۳۰، دویدن، ۲۰ دقیقه کتاب، گفتگو با یک نفر |
| **Side Quest** | اسلات یادگیری هفتگی (کسب‌وکار/اقتصاد)، Forge | «۳۰ دقیقه کسب‌وکار» |
| **Boss** | باس هفتگی/قلمرو/آزمون | جمعه |
| **Comeback** | بعد از یک روز Miss | «۱۵ دقیقه، ۳ تست» |
| **Bonus (Event)** | رویداد تصادفی هفتگی | «۲۰ تستِ زمان‌دار؛ XP دو برابر» |

### 5.2 سه سطح هر مأموریت (Goldilocks + قانون دو دقیقه)
| سطح | معنا | اثر |
|---|---|---|
| **Seed** | حداقل (۲–۵ دقیقه): «کتاب را باز کن و ۳ تست بزن» | روز «از دست‌رفته» حساب نمی‌شود؛ بدون جریمه؛ XP ۲۵٪ |
| **Standard** | سهم عادی روز | XP کامل، سپر/جریان (Flame) |
| **Stretch** | ≈ +۲۵٪ | XP کامل + Gold + شانس Loot |

### 5.3 مشخصات هر مأموریت (ذهن‌پاک — حذف تصمیم‌گیری)
هر مأموریت ۴ فیلد دارد: **چه موقع (Anchor/ساعت) · چه کاری (دقیق) · معیار موفقیت (عدد) · نسخهٔ Seed**.
مثال: «بعد از صبحانه · ۱۰ تست مبانی · موفقیت = ۱۰ تا (نه ۹) · Seed = ۳ تست».

### 5.4 حداکثر مأموریت فعال
حداکثر **۵ مأموریت در روز** (Core + ۲ Fixed + ≤ ۲ ستون). بقیه «در انتظار» می‌مانند (کاهش بار شناختی).

## 6. امتیاز منفی، جریان و بازگشت

### 6.1 جریمه‌ها (SS)
| رویداد | SS |
|---|---:|
| Core Quest انجام‌نشده (حتی Seed هم نه) و بدون عذر موجه | −20 |
| هر Daily Fixed انجام‌نشده | −6 |
| هر مأموریت ستون انجام‌نشده | −4 |
| رد کردن Weekly Boss | −40 |
| **سقف روزانه** | −40 |
| **سقف هفتگی** | −120 |

### 6.2 سپر و رخداد زندگی
- **Shield:** برای هر ۵ روز متوالی با حداقل Standard یک سپر (سقف ۳). مصرف دستی ≤ ۲۴ ساعت بعد؛ جریمهٔ آن روز را لغو و Flame را حفظ می‌کند.
- **Life Event:** اعلام «امروز شرایط غیرعادی است» (دانشگاه، بیماری، سفر) با یک خط توضیح؛ ≤ ۲ بار در هفته؛ بدون جریمه؛ Planner ظرفیت را بازتنظیم می‌کند. اگر در ماه > ۴ بار، پیام بازتاب (Reflection) نشان داده می‌شود.

### 6.3 Flame و Consistency
- **Flame:** روزهای متوالی با Core ≥ Standard. شکننده است → فقط تزئینی.
- **Consistency Rate (مبنای واقعی):** درصد روزهای ۷ و ۳۰ روز اخیر با Core ≥ Seed. این عدد در Rival و Achievements استفاده می‌شود.
- **Never Miss Twice:** بعد از یک روز Miss، نشان «Recovery» با انجام Comeback.

### 6.4 Comeback Mechanic
- شرط فعال‌شدن: ۱ روز Miss (پیشنهاد اولیه) یا ۳ روز با Consistency پایین.
- مأموریت: **Seed + ۱۵ دقیقه**؛ یک کار کوچک و مشخص.
- اثر: ۵۰٪ جریمهٔ آن روز برمی‌گردد؛ Achievement «Comeback Kid»؛ مه روی نقشه کمی عقب می‌رود.
- **بدهی انباشته نمی‌شود:** فصل‌های نرسیده به صف Triage می‌روند، نه روی دوش فردا.
- حالت «Reset Week»: اگر هفته‌ای با Load Ratio > 1.3 به هم ریخت، یک دکمهٔ «شروع هفته از نو» برنامه را بازتنظیم می‌کند و جریمهٔ هفته به ≤ ۵۰ محدود می‌شود (یک‌بار در ماه).

## 7. Shadow Rival

### 7.1 مفهوم
یک رقیب **سایه‌ای و فرضی** که با «مسیر ایده‌آل» پیش می‌رود. (پیش‌فرض: بدون آدم واقعی؛ نسخهٔ آینده امکان دوست واقعی.)

### 7.2 الگوریتم
```
MP(t)         = مجموع وزن فصل‌های برنامه‌ریزی‌شده تا هفتهٔ t    # Mastery Points (وزن‌ها: M=3, S=2, C=1)
pace p        ∈ [0.85, 1.10]، شروع = 1.00
هر یکشنبه:   p_next = clamp( 0.5·p + 0.5·(user_pace_4w × 1.05), 0.85, 1.10 )
Shadow(t)     = MP(t) × p
Shadow_acc(t) = درصد خالص هدف هفته (خطی از a0_baseline تا هدف ۳۵٪)
```
- اگر کاربر ≥ ۲۰٪ پشت Shadow ماند برای ۲ هفته: رویداد «**Shadow Rests**» (رقیب زخمی می‌شود، فاصله ۱۰٪ کم می‌شود). Rival هیچ‌وقت غیرقابل‌شکست نیست.
- شفافیت: همهٔ محاسبات با «چرا؟» قابل‌مشاهده.

### 7.3 دوئل هفتگی (۵ راند)
1. Mastery Points کسب‌شده
2. درصد خالص تست‌ها
3. تعداد تحلیل خطا
4. Consistency Rate هفته
5. نتیجهٔ Weekly Boss

برنده = **Best‑of‑5**. برد: +Gold و Loot؛ باخت: ثبت «چه چیزی بزنی تا ببری».

### 9.4 Builder Hour (پاداش خلاقانه)
- ساعتی برای کدزدن/ایده/پروژه‌ی شخصی (بخش 01 §7).
- **باز شدن:** در پایان هفته، اگر Consistency ≥ ۷۰٪ و (Core کامل ≥ ۴ روز) → ۱ ساعت؛ + ۱ اگر Weekly Boss شکست خورد؛ + ۱ اگر دوئل برده شد. سقف ≈ ۳ ساعت.
- قابل ذخیره‌کردن ≤ ۶ ساعت؛ نه قابل خریدن با Gold.
- در Builder Hour از Idea Vault بالاترین ارزش را انتخاب می‌کنی.

### 9.5 Loot (پاداش متغیر)
پس از تکمیل روز Standard: یک رول تصادفی (۶۰٪ هیچ، ۲۵٪ تکهٔ داستان Codex، ۱۰٪ cosmetic، ۵٪ Shield). **Pity timer:** هر ۷ رول بدون جایزه، یکی تضمین‌شده.

## 11. جلوگیری از بازی‌کردن سیستم (Anti‑Gaming)
- XP زمان فقط از تایمر؛ idle detection (۵ دقیقه عدم تعامل ← مکث).
- ورود دستی > ۲۴ ساعت: ۵۰٪ XP + برچسب.
- Clear فصل نیاز به **دو جلسهٔ تست فاصله‌دار** (حداقل ۲ روز فاصله) و درصد خالص ≥ ۶۰٪ دارد.
- سقف روزانهٔ هر منبع XP (جدول بالا).
- هفتگی: AI یا قاعده‌های ساده ناهنجاری را علامت می‌زند (مثلاً ۲۰۰ تست در روز با ۱۰۰٪ دقت).
- **Honesty Pact:** بازی علیه خود است؛ ورود داده شخصی است؛ ناهنجاری فقط «هشدار» می‌دهد، مجازات نمی‌کند.

## 12. مجموعهٔ قوانین نمونه (برای تست پذیرش)
1. کاربر ۳۰ دقیقه تایمر + ۱۰ تست (۷ درست، ۲ غلط، ۱ نزده) + ۲ تحلیل خطا: XP = 6 + (7×0.6 + 2×0.1) + 2×1.0 = 6 + 4.4 + 2 = **12.4**.
2. کاربر Core را انجام نمی‌دهد و عذری ندارد: SS −20 (+ −6 برای Fixed که انجام نشده) ← سقف −40.
3. کاربر Seed انجام می‌دهد: بدون جریمه، XP = ۲۵٪.
4. سه روز Miss پشت‌سرهم: روز اول Comeback ۵۰٪ جریمه را برمی‌گرداند؛ روز دوم و سوم جریمه سقف دارد؛ بدهی منتقل نمی‌شود.
5. هفتهٔ با Load Ratio > ۱.۳: دکمهٔ Reset Week؛ جریمه ≤ ۵۰.
